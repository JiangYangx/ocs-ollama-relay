# 拿到之后怎么用（给使用者）

这份文档是写给**拿到本项目、但不是开发者**的人看的。
不需要懂 Python，不需要读源码，按顺序做即可。

---

## 0. 先分清你是哪种使用者

| 你的情况 | 用哪条路 | 需要准备什么 |
|---|---|---|
| 只想跑起来用，不想装环境 | **A. 用打包好的 exe** | Windows 电脑 + 一个模型（云端 Key 或本地 Ollama） |
| 电脑上有 Python，或想改代码 | **B. 跑源码** | Python 3.9+ + 同上 |
| 一台电脑给同寝室/同事几个人共用 | **C. 局域网共享** | 一台常开的电脑 + 令牌 |

> **最重要的一句话**：这个程序是**跑在你自己电脑上的中转服务**，不是别人搭好的公共服务器。
> 所以每个人都要：① 自己运行一份；② 自己准备模型和 Key。
> 别人的 API Key 不能借你用，你的 Key 也不要打包发给别人。

## A. 用打包好的 exe（推荐给普通使用者）

### 第 1 步：拿到并解压

从 Release 页下载 `JY-Relay.exe`，放到一个**自己有写权限的普通文件夹**，例如：

```
D:\JY-Relay\JY-Relay.exe
```

⚠️ 不要放 `C:\Program Files`、`C:\Windows` —— 那里没有写权限，配置存不下来。

首次双击如果 Windows 弹出蓝色提示「已保护你的电脑」：

> 点 **更多信息** → **仍要运行**。

杀毒软件报毒也属常见（PyInstaller 打包的程序容易被误判），确认来源可信后加白名单即可。

### 第 2 步：准备「大脑」（模型）

二选一，**必须有一个**，否则程序能启动但答不出题。

**① 云端模型（不用显卡，最省事）**

到 [智谱开放平台](https://open.bigmodel.cn/) 注册 → 实名 → 创建 API Key。
免费档是 `glm-5.3-flash` 系列（以控制台下拉列表里实际存在的免费型号为准）。

拿到三样东西记下来：

| 项 | 值 |
|---|---|
| api_base | `https://open.bigmodel.cn/api/paas/v4` |
| api_key | 你自己创建的那串 Key |
| 模型名 | `glm-5.3-flash` |

**② 本地模型（离线、免费、要显卡）**

装 [Ollama](https://ollama.com/download)，然后命令行执行：

```bash
ollama pull qwen2.5:7b-instruct
```

显存小就换 `qwen2.5:3b`。

### 第 3 步：启动

双击 `JY-Relay.exe`。会出现一个黑色命令行窗口（**别关它**，关了服务就停了），
几秒后浏览器自动打开控制台：

```
http://127.0.0.1:5000/
```

没自动打开就手动在浏览器输入这个地址。

### 第 4 步：在控制台配好模型

控制台 →「模型接入」标签页：

**用云端**：后端切到「云端 OpenAI 兼容」，填 api_base、api_key、主模型，点保存。
**用本地**：后端保持「本地 Ollama」，`ollama_url` 保持默认，主模型选你 pull 过的那个。

填完点右上角「**自检**」，8 项里不该有红色 ✗。
（常见红色：api_base 少了 `https://`、模型名拼错、Ollama 没启动。）

### 第 5 步：把配置复制给客户端

控制台 →「**接入客户端**」→ 点「复制配置」。
得到一段 JSON，形如：

```json
[{
  "name": "本地AI中转",
  "homepage": "http://127.0.0.1:5000/",
  "url": "http://127.0.0.1:5000/api/qa",
  "method": "post",
  "type": "GM_xmlhttpRequest",
  "contentType": "json",
  "responseType": "json",
  "data": {
    "title": "${title}",
    "options": "${options}",
    "type": "${type}",
    "images": { "handler": "return (env) => env.images || []" }
  },
  "handler": "return (res) => [res.question, res.answer]"
}]
```

### 第 6 步：粘到你的客户端里

打开你用的答题客户端 / 脚本 → 题库设置 → 添加「自定义接口」→ 把上面整段 JSON 原样粘进去 → 保存 → 测试。

能返回答案就通了。想验证服务本身是否正常，浏览器打开 `http://127.0.0.1:5000/api/health`，返回 JSON 即正常。

## B. 跑源码（给会用 Python 的人）

```bash
git clone https://github.com/JiangYangx/ocs-ollama-relay.git
cd ocs-ollama-relay
pip install -r requirements.txt
python ocs_relay.py
```

Windows 也可以直接双击 `start.bat`（会自动检查并补装依赖）。

其他常用参数：

```bash
python ocs_relay.py --port 5001        # 5000 被占用时换端口
python ocs_relay.py --host 0.0.0.0     # 允许局域网访问
python ocs_relay.py --no-browser       # 不自动开浏览器
```

**只要一个文件也能跑**：把 `ocs_relay.py` 单独拿走，`pip install flask requests` 后执行即可，其余文件都可以不要。

## C. 一台机器，多人共用

适合：办公室/寝室只有一台有显卡的电脑，其他人想共用。

### 服务端（那台常开的电脑）

1. 启动时加 `--host 0.0.0.0`：

   ```bash
   python ocs_relay.py --host 0.0.0.0
   ```

2. **必须设访问令牌**：控制台 →「高级」→ `auth_token` 填一串随机字符（如 `jy-8f3a92c1`）→ 保存重启。

   > 不设令牌等于把你电脑上的模型服务对整栋楼开放，谁都能白嫖你的额度。

3. 放行防火墙 5000 端口：Windows 安全中心 → 防火墙 → 允许应用通过防火墙 → 勾选 Python / JY-Relay（专用网络）。

4. 查本机内网 IP：

   ```bash
   ipconfig
   ```

   找 `IPv4 地址`，例如 `192.168.1.20`。

### 使用者（其他人的电脑）

控制台打不开别人的 `127.0.0.1`，必须换成服务端的内网 IP。
把客户端配置里的两处地址改掉，并加上令牌头：

```json
{
  "url": "http://192.168.1.20:5000/api/qa",
  "headers": { "X-Relay-Token": "jy-8f3a92c1" }
}
```

浏览器访问控制台则用：

```
http://192.168.1.20:5000/?token=jy-8f3a92c1
```

> 令牌有三种带法：请求头 `X-Relay-Token`、URL 参数 `?token=`、Cookie。客户端用第一种最稳。

共用时注意：所有题都排在同一个队列里，人多会变慢；题库和订正库也是**共享**的（这其实是好事，一个人订正过，所有人都受益）。

## 每个人必须自己有的东西

| 东西 | 能不能共用 | 说明 |
|---|---|---|
| 中转程序 | 同机可共用 | 每人一份也行，互不影响 |
| 云端 API Key | **不能** | 绑账号、有额度和风控，共用容易一起被封 |
| 本地 Ollama 模型 | 可共用 | 局域网指向同一台即可 |
| 题库 / 订正库 | 可共用 | 文件在程序目录下，共用一份效果更好 |
| 端口 5000 | 同机不行 | 同一台电脑跑两个实例要改端口 |

## 常见卡点

| 现象 | 原因 | 处理 |
|---|---|---|
| 双击后黑窗一闪而过 | 缺依赖或配置损坏 | 改用命令行 `python ocs_relay.py` 看报错 |
| 浏览器打不开 127.0.0.1:5000 | 服务没起来 / 端口被占 | 看黑窗日志；`--port 5001` 换端口 |
| 自检提示「云端无 xxx 模型」 | 模型名拼错或该账号没有 | 用控制台下拉列表里的实际型号 |
| 编程题/填空题返回空 | token 上限太小，被思考链占满 | 「正确率增强」里把 token 上限调到 2048 |
| 图片题答不对 | 没配视觉模型 | 配 `glm-4v-flash` 或本地 `qwen2.5vl:7b` |
| 每次都要等很久 | 首次加载模型 | 正常，之后有缓存会快 |
| 局域网连不上 | 防火墙 / IP 写错 | 关掉防火墙试一次，确认是同一网段 |

更多排查见 [`FAQ.md`](FAQ.md)，接口细节见 [`API.md`](API.md)。

## 几条底线

- **API Key 只放自己电脑**：不要截图外发、不要提交到 Git、不要打包进压缩包发给别人。
- **不要开公网**：`0.0.0.0` 只用于局域网，别做端口映射到公网。
- **题库和日志是本地的**：默认存在程序目录，觉得敏感就定期删 `bank.json`、`corrections.json`、`relay.log`。
- **用途自负**：本项目只是协议中转层，把它接到哪里、怎么用，由使用者自己负责，并需遵守所在平台的服务条款。
